# 小番茄溫室作業板

溫室土耕小番茄的線上工作清單。員工打開網址就能用,不需要任何帳號;管理者用密碼登入。

- **員工**:選自己的名字,只看到分派給自己的工作;可勾「已完成」,或勾「尚未完成」並填寫原因;全期進度唯讀。
- **管理者**:看到全部工作與每個人的進度、分派人員、改狀態、寫備註、改排程與人員名單。
- **資料直接存進管理者的 Google 試算表**:員工回報、分派、狀態、備註都會自動寫進試算表,管理者隨時打開就能看,也能「檔案 → 下載 → Microsoft Excel」存成 Excel。
- **工作紀錄**:網頁上可依月份、人員、紀錄表篩選,按「匯出本月工作紀錄」可存成 Excel(分頁對應計畫排程表的 6 張紀錄表)。
- **空白排程表**:管理者畫面右上角有「下載空白排程表」按鈕,可下載種植工作計畫排程表的範本(不含網頁上的分派與回報資料)。

網頁放在 **GitHub Pages**(免費),資料存在管理者自己的 **Google 試算表**(透過 Apps Script,免費)。

## 檔案說明

| 檔案 | 用途 | 需要修改嗎 |
|---|---|---|
| `index.html` | 網頁本體 | 不用 |
| `app.js` | 工作排程與畫面邏輯 | 不用 |
| `sheet-config.js` | 試算表連線網址 | **要填**(步驟 4) |
| `apps-script.gs` | 貼到 Google 試算表的程式 | **要改密碼**(步驟 2) |
| `docs/tomato-plan.xlsx` | 溫室土耕小番茄_種植工作計畫排程表 | 要更新時,用同檔名重新上傳 |

> 還沒填 `sheet-config.js` 時,網頁會以「示範模式」開啟,可以先看畫面,但資料不會儲存。

## 試算表裡會有什麼

| 分頁 | 內容 |
|---|---|
| 工作紀錄 | 每一次回報、分派、狀態變更、備註,一筆一列(日期、時間、工作、紀錄表、人員、動作、說明) |
| 工作狀態 | 每項工作目前的狀態、負責人、管理者備註 |
| 員工回報 | 每項工作最新的員工回報(完成/未完成與原因) |
| 設定 | 排程參數與人員名單(請在網頁「排程設定」修改) |

可以隨意查看、篩選、下載。**請不要修改第一列標題、「工作代碼」與「ISO時間」欄**,網頁靠這些欄位對應資料。

## 設定步驟(約 15 分鐘,由管理者用自己的 Google 帳號操作)

### 1. 建立 Google 試算表

1. 用 Google 帳號打開 <https://sheets.new>,會新增一份空白試算表。
2. 左上角把名稱改成例如「小番茄作業板資料」。

### 2. 貼上 Apps Script 程式

1. 在試算表上方選單按「**擴充功能 → Apps Script**」。
2. 把編輯器裡原本的內容全部刪掉,打開本專案的 `apps-script.gs`,整份複製貼上。
3. 找到第 10 行 `const INITIAL_PASSWORD = '請改成管理者密碼';`,把引號裡改成你的管理者密碼(至少 6 碼)。
4. 按上方的「儲存」圖示。

### 3. 授權並部署成網頁應用程式

1. 編輯器上方的函式選單選 **`setup`**,按「**執行**」。
2. 跳出「需要授權」→「審查權限」→ 選你的 Google 帳號。
   - 若出現「Google 尚未驗證這個應用程式」,按「進階」→「前往(專案名稱)(不安全)」→「允許」。這是你自己寫的程式,只會存取這份試算表。
3. 執行完成後回到試算表,會看到「工作紀錄、工作狀態、員工回報、設定」4 個分頁。
4. 回到 Apps Script,右上角「**部署 → 新增部署作業**」。
5. 左邊齒輪選「**網頁應用程式**」,設定:
   - 執行身分:**我**
   - 誰可以存取:**所有人**
6. 按「部署」,複製出現的「**網頁應用程式網址**」(以 `https://script.google.com/macros/s/` 開頭、`/exec` 結尾)。

### 4. 把網址填進網頁

1. 到 GitHub 的 repository,點 `sheet-config.js` → 右上角鉛筆圖示(Edit)。
2. 把 `請填入網頁應用程式網址` 換成剛剛複製的網址(保留前後的雙引號)。
3. 按「Commit changes」。等 1–2 分鐘,GitHub Pages 會自動更新。

### 5. 開始使用

1. 打開網址(例如 `https://你的帳號.github.io/tomato-board/`)→ 右上角「管理者登入」→ 輸入密碼。
2. 到「排程設定」確認定植日等參數,按 **「儲存排程設定」**(第一次一定要按,員工端才會讀到設定)。
3. 在「人員名單」新增員工姓名。
4. 回到「今日工作」分派工作。
5. 把網址傳給員工(可加入手機主畫面)。員工第一次打開時點選自己的名字即可。
6. 管理者畫面右上角的「**Google 試算表**」按鈕,可以直接打開存資料的試算表。

## 常見問題

**員工需要帳號嗎?** 不需要,打開網址就能用。

**試算表要分享給員工嗎?** 不用,也不建議。試算表只有管理者看得到,員工透過網頁寫入。

**別人拿到網址會怎樣?** 可以看到工作進度並送出「完成/未完成」回報;但無法分派、改狀態、改排程、人員名單或讀取工作紀錄,這些都要管理者密碼,由 Apps Script 在伺服器端檢查。員工選名字不需驗證,因此網址請只給農場內部人員。

**員工回報後,管理者多久看得到?** 試算表是立刻寫入;網頁畫面每 1 分鐘自動更新一次,切回網頁或重新整理時也會馬上更新。

**為什麼按下去要等一兩秒?** 每次存檔都會寫進 Google 試算表,速度比一般資料庫慢一點,屬正常現象。

**要改管理者密碼?** 登入後到「排程設定 → 變更管理者密碼」。變更後,其他裝置上的管理者登入會被登出。

**忘記密碼?** 打開試算表 →「擴充功能 → Apps Script」,上方函式選單選 `resetPassword` 按「執行」,密碼會回到 `INITIAL_PASSWORD` 的值。

**修改了 Apps Script 程式(包含改 INITIAL_PASSWORD)?** 要重新部署才會生效:「部署 → 管理部署作業」→ 鉛筆圖示 → 版本選「**新版本**」→「部署」。網址不會變,不用改 `sheet-config.js`。

**免費額度夠嗎?** Google 對免費帳號的 Apps Script 有每日執行量限制,一般農場(十幾位人員、每天數十次開啟與回報)的日常使用通常足夠。

**另一座溫室/另一期作?** 建議再建一份試算表與一個 repository,資料才不會混在一起。

**修改工作項目內容?** 工作項目、做法與數值標準寫在 `app.js` 的 `milestones()`(里程碑工作)與 `routines()`(例行工作)。修改後重新上傳 `app.js` 即可。
